> เอกสารนี้สำหรับ Claude Code ที่ทำงานกับ ERP หลักของ Laotai
> อ่านไฟล์นี้ก่อน แล้วใช้ข้อมูลในโฟลเดอร์ `odoo-reference/` เป็นตำราอ้างอิง

## 1. บริบท
- ผู้ใช้: Mone, Finance & Accounting, Laotai Group (ลาว)
- บริษัทมี ERP ของตัวเองที่กำลังพัฒนาอยู่
- เป้าหมาย: ใช้ Odoo Community เป็นตำราอ้างอิง เพื่อทำ gap analysis กับ ERP ของเรา แล้วเขียน spec ให้ทีม dev
- ผู้ใช้อยากให้ ERP มีครบทุก module ในระยะยาว

## 2. ข้อตกลงที่ห้ามละเมิด
1. ใช้เฉพาะ **Odoo Community** (LGPL-3) **ห้ามแกะหรือก๊อป Odoo Enterprise**
2. **เอาแนวคิดและ business logic ไม่ก๊อปโค้ด** ถ้าจะก๊อปโค้ดจริง ต้องให้ฝ่ายกฎหมายตรวจเงื่อนไข LGPL ก่อน
3. ไม่ใช้ REA ให้อ่าน source code ของ Odoo โดยตรง
4. ตอบผู้ใช้เป็นภาษาไทย ตรง สั้น ใช้คำง่าย และแยกให้ชัดว่าอะไรคือข้อเท็จจริง สมมติฐาน ความเห็น หรือคำแนะนำ ถ้าข้อมูลไม่พอ ให้บอกตรงๆ ห้ามเดา
5. ไฟล์ Excel: พร้อมพิมพ์, ฟอนต์ Phetsarath OT ขนาด 12, ธีมสีเขียว (LaoTai), ใช้สูตรแทนการพิมพ์ค่าตายตัว และเกณฑ์ที่สูตรใช้ต้องอยู่ใน cell แยก

## 5. ระดับความน่าเชื่อถือของข้อมูล
| ส่วน | ที่มา | ความเชื่อถือ |
|---|---|---|
| จำนวน module, depends, Model, เมนู, License | สคริปต์อ่านจาก source โดยตรง | สูง |
| คำอธิบายภาษาไทยของ App | ผู้วิเคราะห์เขียนจากชื่อ Model และเมนู ประกอบกับความรู้เรื่อง Odoo | กลาง |
| Dr/Cr ในแผ่น "กระบวนการหลัก" | ความรู้ทั่วไป | กลาง: **ต้องอ่านโค้ดยืนยัน** โดยเฉพาะการตีมูลค่าสินค้า (stock_account ใน 20.0 มี model ใหม่ชื่อ `product.value`) |
| ฟีเจอร์ที่ Community ไม่มี | ค้นใน source แล้ว ยืนยันได้ว่าไม่มี asset, budget, financial reports, payroll, follow-up, consolidation | สูง |
| ชื่อ module ฝั่ง Enterprise และทางเลือกจาก OCA | ความรู้ของผู้วิเคราะห์ | **ต่ำ: ยังไม่ได้เช็คว่า OCA มีเวอร์ชันสำหรับ 20.0 หรือยัง** |

## 6. ข้อค้นพบสำคัญ
1. **Odoo Community ขาดฟีเจอร์ Finance หลัก** ได้แก่ งบการเงินเต็ม, หน้าจอจับคู่ธนาคาร, ค่าเสื่อม/ทรัพย์สินถาวร, งบประมาณ, เงินเดือน และการรวมงบบริษัทในเครือ เรื่องเหล่านี้ต้องอ้างอิงจาก OCA
2. **ไม่มีผังบัญชีและภาษีของลาว** ใช้ `l10n_th` หรือ `l10n_vn` เป็นตัวอย่างโครงสร้างได้
3. **คำแนะนำ (ความเห็นของผู้วิเคราะห์):** อย่าทำทุก module พร้อมกัน ให้ทำเป็นชั้นตามการไหลของเงิน
   - ชั้น 1: บัญชี + ผู้ติดต่อ + สินค้า
   - ชั้น 2: ขาย / จัดซื้อ / คลัง และตัวเชื่อม 3 ระบบนี้กับบัญชี
   - ชั้น 3: POS / ผลิต / เบิกค่าใช้จ่าย / อื่นๆ
